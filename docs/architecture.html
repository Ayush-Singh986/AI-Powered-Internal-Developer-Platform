Services

🌐 Forge Console

FastAPI Three.js

localhost:8501

Operations console for environment health, deployment risk, token-gated read-only workload logs, AI chat, cloud cost planning, and reports.

→ Open Portal (local)

📚 docs-assistant

FastAPI TF-IDF RAG

localhost:8001

Retrieves relevant chunks from runbook markdown files using TF-IDF, then calls llm-gateway to synthesize an answer.

POST /ask {"question": "..."}
→ Swagger UI (local)

📊 model-serving

FastAPI scikit-learn

localhost:8002

Deploy-risk logistic regression. Scores a proposed deployment by files changed, lines changed, test coverage, time of day, recent failures.

POST /predict {"files_changed": 12, ...}
→ Swagger UI (local)

🤖 llm-gateway

FastAPI httpx cache

localhost:8003

Single door to LLM providers. In-memory LRU cache (500 entries), token + cost tracking, mock mode when no API key set.

POST /v1/chat {"prompt": "...", "caller": "portal"}
→ Swagger UI (local)

🚨 aiops-agent

FastAPI asyncio

localhost:8004

Polls Prometheus every 30s. Opens incidents on high error rate or latency. Optionally restarts deployments (ENABLE_REMEDIATION=true).

POST /simulate {"service": "docs-assistant"}
→ Swagger UI (local) → GET /incidents (JSON)

📈 Prometheus

Metrics

localhost:9090

Scrapes /metrics from all 4 services every 5s. Powers the Grafana dashboard and AIOps agent queries.

→ Prometheus UI (local) → Targets

📉 Grafana Mission Control

Dashboards

localhost:3000

Auto-provisioned "IDP Mission Control" dashboard. Request rate, P95 latency, LLM cost, token usage, risk predictions, active incidents.

→ Open Grafana (local) → Mission Control Dashboard

Request Flow

Docs query: Portal → docs-assistant /ask → TF-IDF top-3 chunks → llm-gateway /v1/chat → Anthropic (or mock) → answer + sources back to Portal

Deploy risk: Portal → model-serving /predict → LogisticRegression → risk_level (low/medium/high)

Auto-remediation: aiops-agent polls Prometheus PromQL → breach detected → incident created → llm-gateway for summary → (if enabled) kubectl rollout restart
